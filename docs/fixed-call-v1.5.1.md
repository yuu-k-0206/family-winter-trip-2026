# v1.5.1 固定呼出しボタン

依頼：承認済みの案に沿って、既存機能・配置を維持し、スマホのホーム上へ呼出しボタンを追加、公開する。
基点：main `82523a21aca914097904a782318f5db3ce3a7aee`（PR #26）。

## 実装

- `.bottom-nav` 内に絶対配置。左12px以上、ナビ上約12px、最小104×44px。淡いアイボリー・金枠、常時アニメーションなし。ナビ自体の表示条件・高さ・安全領域に追従する。
- `mascot-roam.js`：現在表示中の安全な余白へ既存の散歩処理を使用。ない場合は右下で最大6pxの小ジャンプ（700ms、2人目は90ms遅延）。新しい画面スクロール処理は追加していない。
- `mascot.js`：明示呼出し時に会話を閉じるコールバックのみ追加。会話エンジン・自動掛け合い・元の絵は変更しない。
- 新旧ボタンは同じ停止設定を参照。ジャンプも散歩と同じ中断処理を共有し、操作・非表示・印刷・動きを減らす設定で停止する。
- 連続呼出しは前のアニメーションを破棄し、古い終了通知が新しい動きを消さないよう同一性を確認する。
- 読み上げ用の応答と、停止理由付きラベルを用意。ナビサイズ変化でも移動を中断する。
- ページ下の既存ボタンとその散歩先はそのまま。旅行データ・保存キー・既存メニュー5リンクは変更なし。共通配信番号を1.5.1へ更新し、テストのキャッシュ番号除去をパッチ番号にも対応。

## 確認

- 既存のNodeテスト6本（site-smoke、mascot-smoke、mascot-scenes、mascot-conversation、mascot-guide、travel-v15）、JS構文、git diff --checkが成功。
- Chromiumのiframeで6ページ×320/375/390/720/1280pxの30条件。スマホでは44px以上のボタン、ナビと右下マスコットとの非重複、横はみ出しなし。PCでは追加ボタン非表示。既存ページ下ボタン1個とナビ5リンクを維持。
- 320×568px文字20px、720×390px横画面、ナビ下余白を34px増やす模擬安全領域で配置を確認。ナビ高70→104pxでも相対位置を維持。
- 余白なしの小ジャンプをcomputed styleの移動量で確認。余白ありの散歩、スクロール位置不変、5回連続呼出しで2人のみ、操作中断を確認。
- おさんぽオフと再読込保存、新ボタンの無効化、再有効化、動きを減らす設定の模擬環境、会話から切替、Enter操作、既存のページ下呼出し、持ち物保存／リセット、ナビからのページ移動を確認。
- しおりに追加ボタンなし。iPhone Safari実機・VoiceOver・OSによる安全領域の実機確認は未実施。模擬環境と実機検証は区別する。
- QAページ・画面画像・distは公開しない。公開はPRを経由し、Pages成功と公開版の配信番号・動作を確認する。
