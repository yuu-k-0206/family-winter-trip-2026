# v1.5 設計・検証記録

対象：家族冬旅行2026。基点：main `5c2d1e8f2e7da6bc6e23f193e14d7eb4d871a9ce`（v1.4）。
依頼：提案3・5・6・7および2人のやんちゃな移動モーションを設計、実装、公開まで。

## 変更と判断

1. 施設名と地域、SAの上下線を明示したGoogle Maps Search URLを作成。地図を開く操作以外の通信や位置取得は追加しない。10施設IDを正本へ追加し、未定の飲食店は地図なし。
2. 7番目のページ `guide.html` をA4印刷専用CSSで用意。通常表示はスマホで縦並び、印刷時は2日を左右に配置。時刻・人数・持ち物・料金は正本から生成。移動案と予約済み夕食を明示的に区別。印刷設定はA4縦、100%、ヘッダー・フッターなし。PDFファイルは保存時点の内容で固定。
3. 朝昼夕夜は日本時間の暦で計算。毎分と画面復帰時に更新。既存SVGの形状は維持、外部画像なし。手動選択を保存できなくても表示は継続。
4. スタンプは旅行日のキーで分離。破損・未知ID・重複を排除、取消・全件リセットの中止・確定・別タブ更新・保存制限に対応。共有データベースなし。
5. マスコットは原本パーツの複製で二人を分離し、交互の先頭、逆方向、折り返し、小ジャンプで追いかけっこ。1回6.2秒。通常は終了／操作後22秒待機、安全な場所がなければ12秒後に再判定。初回／ページ復帰は10秒待機（レイアウト変動時は延期）。
6. 空き領域内の経路全体を測定し、ヘッダー・下ナビ・操作部・図の注記と衝突する場合は実行しない。画面外・狭すぎる領域も除外。装飾はpointer-events:none。スクロール・タップ・キー・入力フォーカス・リサイズ・レイアウト変動で帰還。非表示・印刷・動きを減らす設定で停止。会話は従来通り右下で可能。
7. 通常の閲覧領域を維持するため、散歩用の薄い区切り余白をページ上部、長いページの途中、下部に配置。画面に表示中の安全な領域だけで遊ぶ。
8. 文字拡大検証で、旅館の予約済みラベルが320px時に横へはみ出す既存問題を発見。ラベル折返しとgrid子要素の最小幅を修正。

## 検証結果

- Node：site-smoke、mascot-smoke、mascot-scenes、mascot-conversation、mascot-guide、travel-v15。
- JavaScript構文、git diff --check。
- 正本の既存フィールドと基点の深い比較：元の日程・人数・宿泊・料金・取消・カラオケ・交通費等を変更していないことを確認。追加の施設ID、しおり用短文、スタンプ定義のみ除いて比較。
- 散歩経路：320〜1440px、40px刻み、左右両方向、各キーフレーム間を補間サンプリング。途中に障害物がある経路も拒否。
- Chromiumで7ページ×320/375/390/720/1280pxの35条件：横はみ出し・画像欠損なし。844×390pxの横画面7条件、320×568pxの文字20px拡大7条件（旅館の修正後確認を含む）。スクロールバー分だけ内容幅は小さくなる。
- ブラウザ操作：スタンプ保存・再読込・取消・6個達成・リセット中止／確定。保存禁止のモックでも一時記録と案内表示。動きを減らす設定のモックで散歩操作を無効化。
- 景色4種の表示、手動選択の再読込保存、自動への復帰。日程のタブとキーボード切替、上下線付き地図リンク、華鳳リンクで実際にGoogleマップの華鳳施設詳細へ遷移。
- 既存の持ち物チェック保存・全解除、会話表示、吹き出しのスマホ内収まり。散歩の二人の移動、操作での中断、停止設定の保存。スマホ移動中の要素を測定し操作部に重ならずpointer-events:noneであることを確認。
- しおり：描画後HTMLをWeasyPrintでPDF化しA4一枚を確認、PNGレンダリングで文字欠け・項目欠落・重なりなし。WeasyPrintは検証時のみ使用しサイト依存は追加していない。

## 検証の範囲と注意

- iPhone Safari実機・VoiceOver・OSのPDF保存操作は未検証。クラウドChromiumの印刷ダイアログが表示されないため、A4一枚の印刷レイアウトは別レンダラーで検証した。ブラウザや印刷設定による差は残る。
- マップはGoogleの検索結果に依存する。現在地からのナビ開始は利用者が地図アプリで選ぶ。上下線・施設は表示先で確認する。
- 地図リンクはユーザー操作で外部サイトを開く。スタンプや設定は端末・ブラウザだけの保存で、家族への共有・同期ではない。
- 保存したPDFの自動更新・プッシュ通知・リアルタイム居場所・写真アップロードは実装対象外。
- テスト用画面、PDF、スクリーンショット、distは公開ファイル／コミットに含めない。
