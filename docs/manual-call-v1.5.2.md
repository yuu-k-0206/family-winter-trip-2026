# v1.5.2 固定ボタンから余白なしでも散歩

## 変更内容

ユーザーの「余白がなくても押したタイミングで動いてよい」という追加指定を反映。v1.5.1の固定ボタン専用の小ジャンプ応答を置き換えた。

- 固定の「2人を呼ぶ」は、見えている余白を優先し、見つからなければ画面内の本文に重ねて6.2秒の追いかけっこを開始。スクロール位置を変更しない。
- 代替経路は画面の左右に20px以上の余裕を取り、上部ヘッダー・下部ナビ・左右の固定操作を避ける。極端に狭い表示領域では開始せず案内する。
- 移動要素はpointer-events:noneのまま。スクロール、タップ、キー操作、フォーカス、画面変更、非表示、印刷による中断を維持。連続呼び出しは前回を終了してから開始。
- 自動散歩と従来のページ下部ボタンは従来どおり余白内。停止設定・動きを減らす設定、会話、保存キー、旅行情報、マスコット原画、ボタン配置を変更しない。
- 7ページの参照番号をv1.5.2に更新。しおりにはマスコットを追加しない。

## 検証

- 経路の単体検証：4幅×3高さ×2方向、計24条件で画面内と固定操作との分離を確認。使用できない極小領域では生成を拒否。既存の障害物回避テストも継続。
- Chromeの実表示：320×568、375×812、390×812、720×390のiframeで余白がないホームから2人が出現し、固定操作より上に収まることを確認（デスクトップのスクロールバー分は表示幅から除外）。
- マスコットのある6ページで固定呼び出しを確認。スクロールで終了、移動中の下部ナビ操作、5回連続押下でも2人だけ、停止設定で呼出し無効、従来のページ下部ボタンで開始を確認。
- site-smoke、mascot-smoke、mascot-scenes、mascot-conversation、mascot-guide、travel-v15の6テストスクリプトとJavaScript構文チェックが成功。
- iPhone実機のSafariでの確認は未実施。
