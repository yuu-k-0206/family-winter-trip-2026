# 家族冬旅行 2026

新潟・月岡温泉への家族旅行を共有する、広告・ログイン不要の静的サイトです。

公開URL: https://yuu-k-0206.github.io/family-winter-trip-2026/

## v1.4 ページ構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | ホーム、概要、重要なお知らせ、キャンセル案内、更新履歴 |
| `hotel.html` | 華鳳の夕食・朝食・客室・温泉、予約・料金記録 |
| `schedule.html` | 2日間の日別工程・寄り道候補 |
| `budget.html` | 交通費、往復4パターンのルート比較 |
| `packing.html` | 持ち物チェックと端末内保存 |
| `styles.css` | 共通スタイルとスマホ下部固定ナビ |
| `script.js` | 共通処理（ページ上に表示先がある場合だけ実行） |
| `trip-data.js` | 旅行データの唯一の正本 |

スマホの画面下に5ボタンの固定ナビ、PCでは画面上部のメニューを表示します。各ページ内は縦スクロールです。旧版のホーム内リンク（`#booking-info` など）は新ページへ転送します。

## v1.5：旅の道具と2人のおさんぽ

- 地図：予定の各施設と旅館にGoogleマップへのリンクを追加。SAは上り／下りを区別し、未定の夕食店舗に推測の場所は付けません。`trip-data.js` の `places` と各工程の `placeId` が対応します。
- 1枚しおり：`guide.html` は現在の仮案（行き魚沼／帰り高速）、予約指定の初日夕食、持ち物、確認事項をA4縦1枚にまとめます。「印刷・PDF保存」からブラウザの印刷画面を使います。日程ページで比較した別ルートは反映せず、旅行データの既定案から生成します。保存したPDFは自動更新されません。
- 景色：日本時間で朝（5〜9時）、昼（10〜15時）、夕（16〜17時）、夜（18〜4時）に切替。手動プレビューもできます。元のイラストの形状を保ったSVGの配色違いです。
- スタンプ帳：`stamps.html` に手動の6スタンプ。押す／取り消す／確認して全件リセット。位置情報・家族間同期は使わず端末内保存。保存できない場合はその場だけ記録し、画面に説明します。
- 2人のおさんぽ：`mascot-roam.js` がページ上部・途中・下部の空き領域やホームのイラスト内で6.2秒の追いかけっこをします。先頭と方向を交互にし、小さなジャンプと折り返しを追加。安全な領域が画面に入っていなければ待機します。操作・スクロール・会話・画面サイズ変更で直ちに右下へ戻ります。停止切替と「2人を呼んでみる」は各ページ下部にあります。
- 従来の足踏み・5秒待機の掛け合い・タップ会話・連打イベントは継続。散歩中は掛け合いを止め、帰還後に再開します。非表示タブ、印刷中、端末の動きを減らす設定では散歩を停止します。

追加ファイル：`travel-utils.js`（日付・地図・保存データ・しおり生成）、`travel-extras.js`（追加ページUI）、`guide.css`。共通CSS/JSの更新番号は全7ページでv1.5に揃えています。しおりページにはマスコットを出しません。

保存キー：`family-trip-scenery`、`family-trip-roaming`、`family-trip-stamps-v1-<出発日>`。既存の持ち物保存キーは変更していません。詳細と検証記録は `docs/travel-v1.5.md` を参照してください。

## v1.4 のブラッシュアップ

- ホーム：カウントダウン直下の4つの入口、重複した日程説明の整理、短い最新情報と折りたたみ式の過去記録。
- 予定：日付付きタブ、時刻・線画アイコンのタイムライン、日別のA/Bルート切替。選択は表示比較のみで、計画や予算を書き換えません。ページ内では各日の選択を保持し、再読込時は行き魚沼・帰り高速の仮案へ戻ります。
- 決定状況：`trip-data.js` の `statusKinds` と `planning` が表示の元です。予約済み・希望伝達済み・仮案・未確認・未予約・一般案内を区別。ホームの確認事項は `booking.pending` を共用します。
- デザイン：既存の紺・ゴールドと採用済みイラストを維持し、`assets/travel-icons.svg` の線画を追加。雪はイラスト内だけで、停止設定は `family-trip-snow` に端末保存。動きを減らす設定・非表示タブでは停止します。

- CSS/JavaScriptのURLに同じ更新番号を付け、古いファイルとの混在を防ぎます。次回変更時も対象の全ページの番号を揃えます。

## 運用方針

- 日程、料金、旅行情報の更新は原則 `trip-data.js` に限定します。予約金額や取消規定は確認前に確定扱いしません。
- 持ち物チェックの保存キー `family-trip-2026-v04-` を維持します。保存は同じ端末・ブラウザ内のみで、家族間で同期されません。
- 公開サイトのため、氏名・住所・予約番号・個人情報を掲載しません。 `noindex` はアクセス制限ではありません。
- 写真は転載せず旅館公式ギャラリーへのリンクを掲載します。
- `main` は本番。変更は作業ブランチ・PRで検証後に公開します。詳しくは `AGENTS.md` を参照してください。

## 右下のマスコット

- しおり以外の6ページが共通の `mascot.css` と `mascot.js` を読み込みます。背景透過の `assets/trip-mascots.svg` は、冬服の子供2人を描いたオリジナルの採用済みデザインの原本です。本人の写真や容姿、ゲームの画像素材は使用していません。
- 現行表示は原本SVGのパーツ定義を `mascot.js` のインラインSVGへ移植して構成しています。元の8コマ画像を左へ送る方式は使わず、キャラクターと影の座標を固定して、両脚と両腕を交互に約0.96秒周期で回転させます。胴体の上下動は最大1.2px。四角い輪郭は維持しつつ、CSSの補間で滑らかに足踏みします。キャラクターのデザイン変更時は原本とインラインSVGの両方を確認してください。
- 横幅は通常スマホ84px、355px以下で76px、PC104px。スマホでは下部ナビの実測高から12px上に配置します。画像の近くにある会話ボタンだけタップ可能で、周囲の余白は背後へ操作を通します。吹き出し内の案内リンクと閉じるボタンは操作できます。画像自体は読み上げ対象から除外し、会話ボタンには操作ラベルを設定しています。
- 端末の「視差効果を減らす」設定では静止表示。非表示タブではアニメーションを一時停止します。

## 2人の自動掛け合い

- `mascot-scenes.js` が各演出終了後に5秒固定で1種類をランダムに選び、2.2秒だけ自動演出します。前回と同じ演出は連続しません。
- `glance`：男の子が女の子に目線を向け、少し遅れて女の子が見返す。目の描画位置だけを移動して元に戻します。
- `poke`：男の子が腕を伸ばし、女の子が軽く跳ねて反応します（身体の接触を厳密に再現するものではありません）。
- `cheer`：男の子→女の子→2人同時の順に短くジャンプします。影は地面に固定します。
- セリフや音声を自動で出しません。タップすると自動演出を即座に止め、従来の会話・怒りイベントを優先します。
- タブを離れた場合・画面の動きを減らす設定では自動演出を停止します。復帰時は新しい待ち時間で再開します。
- タイミングと中断条件は `node tests/mascot-scenes.mjs`、画面構造は `node tests/mascot-smoke.mjs` で検証します。

## マスコットの会話

- `mascot-dialogues.js`：通常5ページ×10種類、お怒り24種類、旅行日限定6種類と設定値。`speaker` は `boy` / `girl`、`text` が本文。ページ・イベントは所属する配列で区別します。通常セリフのページ名はHTMLのファイル名（拡張子なし）に対応します。
- `mascot-conversation.js`：セリフの重複回避・日本時間の日付・連打判定。`trip-data.js` の `departureDate` を毎回参照します。日付差は既存カウントダウンと同じ方法で計算し、日付未設定・不正時は通常会話のみです。
- `mascot.js`：ボタンと1つの吹き出しを生成し、発言者による吹き出しのしっぽ位置とタイマーを管理。吹き出しに「男の子」「女の子」の名前ラベルは表示しません。クリック・タップ・Enter／Spaceで会話し、自動発言・音声はありません。再タップでは古いタイマーを解除して4秒を数え直します。
- 通常時は期間限定セリフを20%の抽選で混ぜます。同一セリフの連続表示は禁止するため、直前が同じ限定セリフなら通常会話へ切り替えます（実際の出現率は20%より低くなります）。
- お怒りは、単調増加する時刻を使って直近3000ms以内の10回目で発動。4秒間は上書きを禁止し、発動から8秒は再発動しません。クールダウン中のタップは蓄積せず、終了後に新たに10回必要です。4秒経過後は通常会話に戻れます。
- タブを離れたときは吹き出しと表示タイマー・連打途中の記録を消去し、足踏みも一時停止。戻っても自動で発言しません。吹き出しに画面の激しい揺れや点滅はありません。

追加テスト：`node tests/mascot-conversation.mjs`。ページ／発言者、重複回避、連打の境界、クールダウン、日本時間の午前0時、日付変更・不正日付、20%の抽選境界を外部依存なしで検証します。

ブラウザ検証（任意）：検証環境にPlaywrightとChromiumを用意し、`node tests/mascot-browser.cjs` を実行します。`PLAYWRIGHT_MODULE` と `CHROMIUM_EXECUTABLE_PATH` で環境側のインストール先も指定できます。サイトの依存パッケージやビルド工程は増えません。20画面条件、会話、実タッチ入力の連打、タイマー、既存機能をローカルHTTPで検証し、スクリーンショットをOSの一時フォルダーへ出力します。実機iPhone Safari・VoiceOverの挙動は別途確認が必要です。
