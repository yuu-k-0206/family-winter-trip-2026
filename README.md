# 家族冬旅行 2026

新潟・月岡温泉への家族旅行を共有する、広告・ログイン不要の静的サイトです。

公開URL: https://yuu-k-0206.github.io/family-winter-trip-2026/

## v1.3 ページ構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | ホーム、概要、重要なお知らせ、キャンセル案内、更新履歴 |
| `hotel.html` | 華鳳の夕食・朝食・客室・温泉、予約・料金記録 |
| `schedule.html` | 2日間の日別工程・寄り道候補 |
| `budget.html` | 交通費、往復4パターンのルート比較 |
| `packing.html` | 持ち物チェックと端末内保存 |
| `styles.css` | 共通スタイルとスマホ下部固定ナビ |
| `script.js` | 共通処理（ページ上に表示先がある場合だけ実行） |
| `trip-data.js` | 旅行データの唯一の正本 |

スマホの画面下に5ボタンの固定ナビ、PCでは画面上部のメニューを表示します。各ページ内は縦スクロールです。旧版のホーム内リンク（`#booking-info` など）は新ページへ転送します。

## 運用方針

- 日程、料金、旅行情報の更新は原則 `trip-data.js` に限定します。予約金額や取消規定は確認前に確定扱いしません。
- 持ち物チェックの保存キー `family-trip-2026-v04-` を維持します。保存は同じ端末・ブラウザ内のみで、家族間で同期されません。
- 公開サイトのため、氏名・住所・予約番号・個人情報を掲載しません。 `noindex` はアクセス制限ではありません。
- 写真は転載せず旅館公式ギャラリーへのリンクを掲載します。
- `main` は本番。変更は作業ブランチ・PRで検証後に公開します。詳しくは `AGENTS.md` を参照してください。

## テスト

`node tests/site-smoke.mjs` で5ページの静的構造、リンク、JavaScript構文、持ち物保存キーを検証できます。Node.jsのみ利用し外部パッケージは不要です。

`node tests/mascot-smoke.mjs` でマスコットの読み込み、ナビ高への追従、非表示時の停止、二重生成の防止を確認できます。

公開前の目視確認：320/375/390pxおよびPC幅、iPhoneの安全領域、各ページ遷移と戻る操作、日別タブ、持ち物保存・リセット、フッター表示。

## 右下のマスコット

- 全5ページが共通の `mascot.css` と `mascot.js` を読み込みます。背景透過の `assets/trip-mascots.svg` は、冬服の子供2人を描いたオリジナルの採用済みデザインです。本人の写真や容姿、ゲームの画像素材は使用していません。
- 1コマ128×112px、8コマ横並びのスプライトを1.6秒で足踏みさせます。差し替え時は同じコマ寸法・順序を維持してください。PNGへ変える場合は `mascot.js` の画像パスも変更します。
- 横幅は通常スマホ84px、355px以下で76px、PC104px。スマホでは下部ナビの実測高から12px上に配置します。画像の近くにある会話ボタンだけタップ可能で、周囲の余白と吹き出しは背後へ操作を通します。画像自体は読み上げ対象から除外し、会話ボタンには操作ラベルを設定しています。
- 端末の「視差効果を減らす」設定では静止表示。非表示タブではアニメーションを一時停止します。

## マスコットの会話

- `mascot-dialogues.js`：通常5ページ×10種類、お怒り24種類、旅行日限定6種類と設定値。`speaker` は `boy` / `girl`、`text` が本文。ページ・イベントは所属する配列で区別します。通常セリフのページ名はHTMLのファイル名（拡張子なし）に対応します。
- `mascot-conversation.js`：セリフの重複回避・日本時間の日付・連打判定。`trip-data.js` の `departureDate` を毎回参照します。日付差は既存カウントダウンと同じ方法で計算し、日付未設定・不正時は通常会話のみです。
- `mascot.js`：ボタンと1つの吹き出しを生成し、発言者表示とタイマーを管理。クリック・タップ・Enter／Spaceで会話し、自動発言・音声はありません。再タップでは古いタイマーを解除して4秒を数え直します。
- 通常時は期間限定セリフを20%の抽選で混ぜます。同一セリフの連続表示は禁止するため、直前が同じ限定セリフなら通常会話へ切り替えます（実際の出現率は20%より低くなります）。
- お怒りは、単調増加する時刻を使って直近3000ms以内の10回目で発動。4秒間は上書きを禁止し、発動から8秒は再発動しません。クールダウン中のタップは蓄積せず、終了後に新たに10回必要です。4秒経過後は通常会話に戻れます。
- タブを離れたときは吹き出しと表示タイマー・連打途中の記録を消去し、足踏みも一時停止。戻っても自動で発言しません。吹き出しに画面の激しい揺れや点滅はありません。

追加テスト：`node tests/mascot-conversation.mjs`。ページ／発言者、重複回避、連打の境界、クールダウン、日本時間の午前0時、日付変更・不正日付、20%の抽選境界を外部依存なしで検証します。

ブラウザ検証（任意）：検証環境にPlaywrightとChromiumを用意し、`node tests/mascot-browser.cjs` を実行します。`PLAYWRIGHT_MODULE` と `CHROMIUM_EXECUTABLE_PATH` で環境側のインストール先も指定できます。サイトの依存パッケージやビルド工程は増えません。20画面条件、会話、実タッチ入力の連打、タイマー、既存機能をローカルHTTPで検証し、スクリーンショットをOSの一時フォルダーへ出力します。実機iPhone Safari・VoiceOverの挙動は別途確認が必要です。
